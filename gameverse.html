Android App · Java · REST APIs

GameVerse

Aplicación Android que consume APIs externas para obtener información de videojuegos en tiempo real, gestionando datos dinámicos y renderizado de UI basado en respuestas REST.

Java Android Studio REST API JSON

Arquitectura

Cliente (Android)

Responsable de UI, navegación y consumo de API.

API Externa

Fuente de datos de videojuegos (RAWG / Twitch APIs).

Procesamiento

Parseo JSON y adaptación de datos a modelos internos.

Funcionalidad

  • Búsqueda dinámica de videojuegos
  • Consumo de APIs REST en tiempo real
  • Renderizado dinámico de listas
  • Manejo de estados de carga y error
  • Interfaz responsive en Android

Demo

Implementación

El sistema está construido sobre una arquitectura cliente que consume datos de APIs externas mediante peticiones HTTP. Los datos se transforman en modelos internos y se renderizan en la UI mediante componentes Android.
